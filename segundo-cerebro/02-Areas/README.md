# 🔁 02 — Áreas

Responsabilidades **contínuas, sem data de fim** — padrões que você mantém ao
longo do tempo. Ex.: "Atendimento ao cliente", "Saúde financeira do consultório",
"Desenvolvimento profissional".

Diferença para Projetos: área não "termina", você só a mantém em bom estado.
