# 🪧 05 — Notas Permanentes (Zettelkasten)

O coração do segundo cérebro. Notas **atômicas** (uma ideia cada), escritas com
suas próprias palavras e **conectadas** entre si por `[[wikilinks]]`.

## Princípios
- **Atomicidade:** uma nota = uma ideia autocontida.
- **Autonomia:** a nota faz sentido sozinha, fora do contexto original.
- **Conexão:** sempre ligue a pelo menos uma outra nota.
- **Suas palavras:** reescrever é o que gera entendimento.

Use o template [[Templates/Template-Nota-Permanente]].
