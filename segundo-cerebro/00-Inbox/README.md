# 📥 00 — Inbox

Captura rápida e indolor. **Tudo** entra aqui primeiro: ideias soltas, links,
trechos, pendências. Não organize na hora de capturar — organize depois.

## Regras
- Capture sem fricção. Uma linha já basta.
- **Processe regularmente** (idealmente na revisão semanal): cada item vira
  nota permanente, vai para um projeto/área, ou é descartado.
- O inbox vazio é o objetivo, não a exceção.

> Novas notas do vault são criadas aqui por padrão (config em `.obsidian/app.json`).
