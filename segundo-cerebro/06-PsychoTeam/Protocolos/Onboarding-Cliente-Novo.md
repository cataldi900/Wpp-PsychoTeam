# 📋 Protocolo — Onboarding de Cliente Novo

Passo a passo para receber um cliente que chega pelo WhatsApp.

## Passos
1. **Criar nota do cliente** em `06-PsychoTeam/Clientes/` usando
   [[Templates/Template-Cliente]].
2. **Enviar saudação** → [[Saudacao-Padrao]] (personalizar o nome).
3. **Enviar PDF** de apresentação (pasta `PDFs/`).
4. **Aguardar e registrar** a primeira resposta no histórico da nota do cliente.
5. **Triagem inicial:** entender a demanda e o melhor encaminhamento.
6. **Agendar** primeira conversa / sessão, se aplicável.

## Boas práticas
- Responder rápido aumenta muito a conversão de cliente novo.
- Tom acolhedor, sem jargão.
- Registrar **tudo** na nota do cliente para dar continuidade.

> ⚠️ Antes de registrar dados pessoais, leia [[Privacidade-e-LGPD]].
