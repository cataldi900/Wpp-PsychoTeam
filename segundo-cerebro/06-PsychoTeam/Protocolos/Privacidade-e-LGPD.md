# 🔒 Protocolo — Privacidade e LGPD

Dados de clientes em contexto de psicologia são **sensíveis** (saúde) e
protegidos pela LGPD e pelo sigilo profissional. Trate com cuidado.

## Regras mínimas
- **Não** versionar no git dados reais de clientes identificáveis. Este vault é
  para **modelos, protocolos e conhecimento** — não para prontuários.
- Anonimize exemplos (use "Cliente A", iniciais ou IDs).
- Coletar só o necessário; guardar pelo menor tempo necessário.
- Acesso restrito a quem precisa.

## ⚠️ Importante neste repositório
Se você for registrar notas de clientes reais, considere manter a pasta
`Clientes/` **fora do git** (adicione ao `.gitignore`) ou em um vault separado e
privado. O exemplo incluído aqui é **fictício**.
